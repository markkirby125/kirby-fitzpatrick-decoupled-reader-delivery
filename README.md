## Overview

The **kirby-fitzpatrick-decoupled-reader-delivery** skill transforms cognitive writing science into deterministic rules for AI coding assistants, code reviews, and system documentation.

## Core Patterns

- **Decoupled Reader Delivery**: Decoupled Delivery Protocol: keep scratchpad reasoning private; deliver only the clean, polished Reader's Draft.
- **Practical Application**: Eliminating internal agent reasoning leaks from user responses.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
